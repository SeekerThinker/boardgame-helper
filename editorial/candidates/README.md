## 人工复核清单（每一条独立填写）

- [ ] 确认来源 URL、访问日期和事实准确性；不复制网页的规则措辞、示意图或例子。
- [ ] 分别审查中文／英文名称、教学表达和示例、所有实际使用的视觉内容；检查计划发行地区及商用、再分发和改编权限。
- [ ] 指定真实撰写者和**不同的**真实审阅者，留审阅日期、证据和未决疑虑。
- [ ] 由真实参与者完成试玩；留人数、轮次、耗时、教学可理解性和无障碍反馈的记录。未实测数据必须写“编辑估计”。
- [ ] 在单独 PR 里提交完整 `rights` / `provenance` / `review` 记录，将状态从草稿改为 `ready`；核对 `isPublishableGame`、完整 CI 和线上检查。

此清单不是自动法律认证。美国版权局 [Games](https://www.copyright.gov/register/tx-games.html) 对游戏方法与文字／美术表达的区分仅适用于其说明的美国版权语境；并不免除不同地区、商标或具体版本的审查。进度追踪见 [Issue #53](https://github.com/SeekerThinker/boardgame-helper/issues/53)。
