桌游助手是一款面向线下桌游聚会的离线桌面助手。简单牌局直接用计时、计分、随机工具和结算；复杂牌局需要时再打开 Table OS，用状态追踪、阶段流程、团队身份、公式计分和战役记录减轻主持与记账负担。

功能亮点：
• 流程主屏：当前玩家、大倒计时、本轮分数和下一轮推进
• 多种计时：回合计时、个人时间池、公共时间池、阶段/讨论倒计时
• 灵活计分：高分胜、低分胜、目标分、历史更正，以及可选高级公式计分
• 状态追踪：生命、资源、威胁、金币、经验等公共/玩家/团队数值
• 阶段流程：可编辑阶段和循环推进，并能一键返回主计时器
• 团队与身份：团队、阵营、身份和主持备注；玩家身份采用两段式私密查看，主持备注不会泄漏
• Campaign / Legacy：战役名称、章节、检查点和跨局备注；追踪器可选择本局重置或跨战役保留
• 桌面工具：掷骰/硬币、随机首家、行动顺序洗牌、均衡分队，并可把最近分队直接用于 Table OS
• 后台提醒：允许通知后，计时结束时发送本地系统提醒
• 离线优先：无需账号、广告、分析或网络，数据只保存在设备本地

Table OS 默认采用精简的牌局模式，只显示正在玩的状态、阶段、身份、分数和检查点；模板、公式、结构编辑与导入导出都收在独立编辑模式，避免在桌上增加新的管理负担。

适合德式策略、派对、低分胜、合作危机、卡牌生命追踪、隐藏身份主持、非对称阵营以及 Campaign / Legacy 等实体桌游。
