Board Game Assistant is an offline table tool for board game hosts. It combines active-player timing, round scoring, editable history, random tools and final results into one focused flow, so game nights are easier to run and scoring disputes are easier to resolve.

Highlights:
• Flow screen: active player, large timer, round scoring and next-round controls
• Timer modes: turn timer, personal clock, shared time pool and phase countdown
• Score templates: victory points, reward/penalty, low-score wins, cooperative campaign and match scoring
• Editable history: review and correct every round, then recalculate rankings automatically
• Tabletop toolbox: dice/coin, random first player, turn-order shuffle and balanced teams
• Background alerts: with permission, a local system alert fires when an active timer reaches zero
• Final results: show ranked totals and copy a session summary
• Offline by design: no account, no ads, no analytics and no network requirement

Use it for strategy games, party games, low-score games, cooperative campaigns, chess-like matches and any board game night that needs a reliable host assistant.
