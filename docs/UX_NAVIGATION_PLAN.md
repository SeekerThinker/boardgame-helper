# 首页与私密发牌调整（2026-09-18）

用户反馈：首页不应把游戏图鉴、桌面 OS 藏在右侧悬浮入口；图鉴应以选择而非搜索为主；秘密发牌不应强制玩家输入牌面。

## 首版实施

- 首页顶部设置同级大入口「选游戏／桌面 OS／工具箱」，主工具和现有存档保持原样；秘密发牌成为工具箱的显眼快捷卡，而非右侧悬浮圆角按钮。桌面 OS 和图鉴打开后利用大版面，不挤占原工作台布局。
- 图鉴首先显示可点击的材料选择和人数选择；文本搜索退居可展开的辅助入口。未有完成权利审核及实测的条目时明确展示空状态，不伪造已审核游戏。
- 秘密发牌提供无需输入的通用随机预设和自动玩家编号；原先的自定义名单、内容、公开主持步骤仍可用。通用预设提供独立撰写的基础词语对和中立身份，并非狼人杀、谁是卧底或其他具体商业游戏的正式角色卡、规则、授权包。
- 预设生成应调用已有安全随机流程；发牌后输入区和全部牌组移出 DOM，单人揭示、后台遮蔽、结束清除、离线及本地隐私行为均不改变。

## 后续内容

具体具名玩法包须另行完成名称、说明文字、词库和素材权利审核、独立教学撰写、真人试玩，方可进入图鉴。此 UX 更新不应被误认为该审核已完成。
